台電會館訂房小幫手

給台電會館教育休閒網的使用者（員工、退休員工、眷屬或獲准人員）。你跟 Claude 說「幫我訂台電會館」，它就會幫你查房、勾房、勾好員工優惠券，停在付款前讓你自己決定。

它能做什麼

預估開放時間每天 9:00 開放到今天起算第 30 天（含今天），幫你推算哪天幾點要搶。
前一天提醒開放前一天傍晚提醒你，再確認一次日期、會館、房型。
自動勾優惠券勾「我要使用在職員工優惠券」和每間房的優惠券框，按重計總額核對。
停在付款前不輸入卡號、密碼，不按「刷卡結帳」，付款由你自己完成。

書籤預設：付款方式信用卡、發票紙本。要改成手機條碼或愛心碼，用記事本打開 txt，改最上面「設定區」的三個值。

事前準備（只做一次）

  1. 在 Claude 的「設定 → 功能 → 技能」上傳 taipower-resort-booking.zip。
  2. 在 Chrome 安裝 Claude in Chrome 擴充功能，登入同一個 Claude 帳號。
  3. 用 Chrome 登入台電會館教育休閒網。
  4. （選用）裝好上面的一鍵填表書籤。

訂房步驟

  1. 對 Claude 說「幫我訂台電會館」。
  2. 回答：哪天入住、住幾晚、哪間會館、哪種房型、信用卡還是 ATM。
  3. Claude 查空房、勾房，在訂單明細頁勾好員工優惠券（顯示 X 的房間沒有優惠）。
  4. 按「下一步」會直接成立訂單（待付款，不是預覽），Claude 按之前會先跟你確認。
  5. 付款自己來：訂單頁按「刷卡結帳」，或到個人專區的訂單資料按「改用ATM」看匯款資訊。

注意事項

  • 「每天 9:00 開放第 30 天」是觀察推算，沒有官方公告，請以首頁橫幅為準。
  • 住宿日前 8～30 天訂房，3 天內繳費；7 天內訂房，當天繳費。逾期自動取消。
  • 60 天內取消 20 間以上，會被停權 4 個月。
  • 會館只供公務、員工、退休員工、眷屬及獲准人員使用，不可轉售營利，違規會永久停權。
  • 網站的使用條款還沒查到是否允許自動化工具，請自行斟酌使用。
  • 公司電腦若禁止書籤執行腳本，書籤可能不能用，但請 Claude 訂房不受影響。
